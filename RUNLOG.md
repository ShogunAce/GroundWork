## Limitations requiring honesty

1. **Bedrock inference is account-blocked.** Connector and CLI both return `ValidationException: Error 002: Access to Bedrock models is not allowed for this account`. Catalog access succeeds. Do not claim successful inference.
2. **Anthropic backup needs a workspace ID.** The supplied unscoped key requires `anthropic-workspace-id`. Workspace discovery returned HTTP 403 missing permissions. No key was printed or deployed. Configure `ANTHROPIC_WORKSPACE_ID` privately or supply a workspace-scoped key.
3. The live UI explicitly reports deterministic fallback. The LLM integration selects energy/start-time preferences; tool sequencing, extraction, grounding and workbook assembly are deterministic. This is not an open-ended LLM tool-selection agent.
4. No generated video loop or separate UI sound-effect files. Motion is coded and the original generated still and narration are self-hosted.
5. Sessions live in server memory, expire after six hours and disappear on restart. Workbook recovery across reloads is not implemented. Download before leaving. Mission checkbox writes use localStorage but do not restore a whole session.
6. Blocks are planning estimates, not appointments. The prototype rules parser may miss unusual phrasing. Review records before sharing.
7. CloudFront-to-viewer uses HTTPS; the restricted CloudFront-to-origin hop uses HTTP. Production hardening should add origin TLS, an origin authentication header, stronger rate limiting, and persistence if needed.

## Exact Bedrock activation

1. Resolve the account model-access restriction with the account owner/AWS support.
2. Confirm a real Converse request succeeds.
3. Set the following server environment (already the deployment defaults):

```dotenv
LLM_PROVIDER=bedrock
AWS_REGION=us-east-1
BEDROCK_MODEL_ID=amazon.nova-micro-v1:0
ALLOW_ANTHROPIC_FALLBACK=false
```

4. Restart locally, or run `sudo systemctl restart groundwork` on the host through SSM.
5. Run the sample and confirm the UI reports AI-selected preferences before changing submission claims.
6. A different Bedrock model also needs the instance role's scoped model resource changed in `scripts/make-infra.mjs` and the stack updated.

For the last-resort Anthropic path, configure `ANTHROPIC_WORKSPACE_ID`, `ANTHROPIC_API_KEY`, and `ANTHROPIC_MODEL` privately. Set `LLM_PROVIDER=anthropic`, or explicitly enable `ALLOW_ANTHROPIC_FALLBACK=true`. On AWS use Secrets Manager or a protected host environment file. Never put credentials in source, user data, public storage, or tool output.
