# Feature requests

- **Critical — Bedrock account preflight:** distinguish IAM permissions, account eligibility, model subscription, and region restrictions before the first invocation. Return the exact next setup step for Error 002.
- **Important — MCP compatibility badges:** show supported protocol revisions beside package versions and examples, particularly across the v1/v2 SDK split.
- **Important — Media-to-project export:** let a completed generated media flow save an optimized file and license/provenance note directly to a local app folder.
- **Important — Provider credential preflight:** expose required workspace headers and model access in one inexpensive check.
- **Nice-to-have — Citizen-science schemas:** community-reviewed, safe observation templates with effort, uncertainty, and evidence fields would help prototypes avoid misleading claims.
